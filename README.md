# TV Latam — Addon de canales

Lista embebida de **~144 canales** en vivo (HLS), agrupados por categoría.  
Adaptado del plugin Kino *TV Latam* al formato **TV Chanel** de lolapp.

## Categorías

Deportes · Canales abiertos · Regionales · Noticias · Cine y series · Novelas · Documentales · Estilo de vida · Infantil · Música · Religiosos · Otros

## Instalación

1. Sube esta carpeta a GitHub (`usuario/tv-latam-addon`).
2. En lolapp: **TV en vivo / Canales → Addons → Instalar desde Git**.
3. Activa **TV Latam**.
